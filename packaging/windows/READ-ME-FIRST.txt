SENTINEL CAMERA RECORDER
========================

To start Sentinel or check that it is recording:

    Double-click  Sentinel.exe

The Sentinel screen shows the recorder status. "Recording normally" means
everything is working. You can close the screen; recording continues.

"Watching for motion" means: outside recording hours Sentinel records only when
something moves. This is normal; no action is needed.

Leaving the computer unattended: press "Lock this computer" (or Windows key + L).
Recording continues while the computer is locked. Do not close the lid or put
the computer to sleep.

If the window shows an error code (for example "Error R-003"), call technical
support and read them the code.

Do not move, rename or delete anything in this folder.


For the installing technician
-----------------------------
* Everything is done in the Sentinel window. Settings are read-only until you
  press "Unlock settings..." and approve the Windows administrator prompt.
* First start: the window opens on "Set up this computer". Tick "Add the camera
  later" if the camera address is not known yet; add it on site in Camera.
* Sections: Status, Recordings, Camera (address, stream, account, Test
  connection), Schedule (work hours / motion), Motion (sensitivity, live test),
  Drives (erase and set up, archive drive, swap), Export (review drives),
  System (install the recorder service, time server, diagnostics, settings file).
* Install the recorder service (System > Service) so recording starts with
  Windows. Until then someone must open Sentinel.exe after every restart.
* Settings and recordings: C:\ProgramData\Sentinel\ (see "Sentinel.exe about").
* The same tasks are available as commands for scripting and support
  (Command Prompt in this folder): Sentinel.exe about [--verify], check-config,
  status, diagnostics, stop, setup [--camera-later], set-camera, schedule,
  motion-test, drives list|prepare|eject, archive ..., export run|status,
  ledger head|verify (recording-log chain head for the custody form at every
  drive swap; Command Prompt as administrator).
* licences\ contains the third-party licences and SOURCE-OFFER.txt.
* ffmpeg\ contains FFmpeg and its licence; see ffmpeg\FFMPEG-LICENCE-NOTE.txt.
